# 本机看板优化快照与统一合并说明

本分支保存基于原安装版本 `9572bcf` 的本机优化，供与其他机器上的实现统一合并。发布前已在本机备份原安装版本、当前 Skill、文件校验清单及工作区差异；备份和运行数据不包含在提交中。

## 相对原安装版本的改动

| 改动 | 原安装行为 | 本机实现 |
| --- | --- | --- |
| 两种任务色块 | 运行、完成、等待、中断、失败和未知均可占用色块 | 只显示开发中、完成待阅读；其他状态不占用色块 |
| 已读联动 | 完成后持续保留 | 只读桌面应用的本机未读任务 ID；普通未读任务变为已读后移除 |
| 历史未读任务 | 启动前已完成任务不收录 | 启动时也收录已完成且未读的普通任务 |
| 自动已读防漏读 | 无保护 | 若运行期间观察到任务刚完成、原生状态已是已读，暂时保留至下一轮开发或其他明确生命周期状态 |
| 自动化排除 | 只排除归档和内部子代理 | 数据库有 `thread_source` 列时排除 `automation`，不通过标题猜测；开发中和完成未读均排除 |
| 读取故障 | 旧任务转为灰色色块 | 显示页面提示并清空色块，恢复后自动刷新，避免保留过期成功状态 |
| 页面说明 | 完成数量和多色图例 | 开发中、完成待阅读数量与两色图例，明确暂时保留规则 |

Skill 内修改四个文件：`SKILL.md`、`assets/index.html`、`scripts/status_reader.py`、`scripts/server.py`。`scripts/board.py` 和 `agents/openai.yaml` 与原安装版本一致。仓库同时更新 README、回归测试和本说明。

## 验证与已知限制

- 发布前在 macOS / Python 3.9.6 执行 `python3 -m unittest discover -s tests -q`：31 项通过；`git diff --check` 通过。
- 回归覆盖历史未读收录、已读移除、新一轮开发、自动已读保护、任务来源过滤、来源变更、异常读取恢复、失效状态隐藏，以及原有启停与实例复用。
- 自动化来源测试使用相同显示标题的普通任务和自动化任务，验证筛选不依赖标题。
- 已安装代码与工作区 Skill 文件校验一致，真实页面确认自动化被排除、普通开发和完成待阅读任务保留。
- **尚未实现“持续打开的任务在离开再进入后自动移除”。** 原生已读标记无法证明用户重新进入；防漏读仅是保守保留策略，不是完整的阅读识别。
- 防漏读保留仅在后台进程内保存。重启后依据原生未读列表重新收录；它不是持久化阅读队列。
- 如果完成时第一次轮询看到的是未读，后续自动标为已读仍可能按普通未读任务移除；保留策略不具备当前活动页面识别能力。
- 如果看板启动时任务因记录陈旧或等待输入而未收录，随后同一轮直接完成且已自动已读，可能记录了保留标记却仍未生成色块；目前收录条件未纳入该标记。复核以纯内存测试桩复现，留待统一合并时修复。
- 缺少 `thread_source` 列的旧数据库仍可读取，但不能保证自动化排除完整。不能将本机来源过滤验证推广到所有旧版本。
- 已读状态缺失、格式变化或读取失败时，本分支暂时隐藏所有任务色块，包括运行中任务。该降级策略需在统一合并时评估。
- 本机已读接入依据随 Codex CLI 0.153.3 分发的桌面应用实现；Windows 的真实桌面已读联动未在本机验证。仓库现有 CI 使用临时测试数据，不代表真实桌面行为验收。

## 与发布时主分支的关系

发布准备时，`origin/main` 已从 `9572bcf` 前进到 `1667a31`（`feat: follow Codex read state with two automatic task states`）。本分支保留原基线上的本机实现，尚未整合该提交，因此应作为**草稿快照**审阅，不应直接覆盖新版文件。

| 主题 | `1667a31` 主分支 | 本机快照 | 合并建议 |
| --- | --- | --- | --- |
| 两态与历史未读 | 已实现 | 已实现 | 合并重复实现与对应测试 |
| 自动化来源排除 | 没有相同的来源过滤 | 按 `thread_source` 排除 | 单独移植筛选及回归测试 |
| 自动已读保护 | 直接跟随未读标记 | 有进程内保留，存在上述限制 | 单独评估策略，不宣称完整阅读识别 |
| 异常状态 | `attention` 单独返回 | 色块隐藏，没有新增同名响应字段 | 保持最终 API 与页面一致 |
| 已读读取失败 | `read_state_error`，运行任务可继续显示 | 顶层 `error`，全部色块暂隐藏 | 优先保留主版本更细的降级能力，再整合本机改动 |
| 版本与启动输出 | 服务版本 0.2.0，启动器增加已读错误信息 | 沿用原安装版本字段与启动器 | 保留主版本的版本号和启动器增强 |

统一合并应保留主分支已有能力，逐项迁移本机独有改动并重新测试。预期在读取逻辑、页面、说明及测试文件上存在交叉改动，不能按“整文件取本分支”处理。
